# Glow AI — AI Skincare and Haircare Recommendation System

## Project Overview
Glow AI is a web-based application designed to analyze skincare and haircare ingredient compatibility and recommend suitable ingredients and compatible products based on users' selected skin and hair concerns.

## Technologies Used
- **Programming Language:** Python
- **Backend Framework:** Flask
- **Frontend:** HTML, CSS
- **Database:** SQLite
- **ORM:** SQLAlchemy
- **Security:** Bcrypt password hashing

## Key Features
- User registration and login
- Skincare and haircare concern analysis
- Ingredient compatibility analysis using rule-based logic
- Personalized ingredient and product recommendations
- User analysis history
- Admin dashboard for product management

## How It Works
- Users select their skin type and skin concerns, and/or their hair type and hair concerns.

- Glow AI processes the selected information using rule-based recommendation logic.

- The system displays suitable ingredients and recommended skincare and haircare products.

- Users can follow external shopping links to purchase recommended products.

- Registered users can access their previous analysis history.
